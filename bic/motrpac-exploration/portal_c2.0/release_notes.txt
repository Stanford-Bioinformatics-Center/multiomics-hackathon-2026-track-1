1. Overview & Quick Reference
This document describes the human-precovid-sed-adu analysis data collection and focuses on Levels 2–4
(see detailed description of data levels) analysis results derived from the corresponding human pre-suspension
(before the Covid-19 pandemic) quantification and identification results. In brief, Level 2 (qc-norm) provides
quality-controlled normalized data used as feature-by-sample matrices for downstream analysis; Level 3 (da)
provides differential abundance (DA) results (models/contrasts with effect sizes and multiple-testing
adjustments); and Level 4 provides downstream interpretation resources (e.g., enrichment and integrative
outputs) when present. Key details are provided below:

   -​   Data collection name / code: MoTrPAC pre-suspension (pre-COVID) human sedentary adults /
        human-precovid-sed-adu (PreCAWG).
   -​   Species / cohort / age: Homo sapiens / adult sedentary participants, pre-COVID / ~18–73 years.
   -​   Current data collection version: v1.3
   -​   Recommended version for new analyses: v1.3.
   -​   Last release update: 2025-05-07 (known issues update in the consortium release readme).
   -​   Data Levels included: Levels 2–4 (analysis results).
   -​   Restrictions:
           -​ Open access: Level 3 (da) and 4 (integrative)
           -​ Data access restriction: Level 2 (qc-norm) and any associated phenotypic data. Individual level
               data is not openly available at this time. Access can be obtained via data access committe
               approval. Please inquire at motrpac-data.org for access.
   -​   Dataset structures:
           -​ Level 2 qc-norm matrices (plus sample/feature metadata) organized by ome and tissue;
           -​ Level 3 differential abundance (DA) tables
           -​ Level 4 enrichment / integrative outputs (e.g., CAMERA and clustering-based enrichment
               results).
           -​ A centralized feature map (HUMAN_FEATURE_TO_GENE) supports feature-level joins across
               omics and downstream annotation.

2. Narrative Summary
The human pre-COVID pre-suspension data include an adult sedentary cohort whose multi-omics data are
permitted for analysis under DSMB constraints. The analysis collection focuses on the acute bout response by
comparing timepoints relative to pre-exercise baseline and comparing changes in exercise groups (endurance
[EE], resistance [RE]) to matched changes in controls (CON) (“difference in changes”). Below is a visual
overview of the study and the available data. See publication for details.
(A) Overview of the acute exercise bout. Baseline testing is completed before randomization. After randomization, a familiarization
period for exercise is completed. Patients arrive in the morning, fasted, to complete their respective interventions. Created in
https://BioRender.com.
(B) Schematic of muscle, blood, and adipose biospecimen collection. No samples are collected during resistance exercise. Created in
https://BioRender.com.
(C) Number of samples measured in each omic category (on any assay) by tissue, exercise modality and timepoint. See
Supplementary Figure S1 to see overlapping measurements for all participants. ATAC = Assay for Transposase-Accessible Chromatin
The analysis collection transforms processed omics results into analysis-ready matrices and statistical
results. As described in the quick reference, data objects are available for download from the Data Hub or can
be accessed via R package (release pending) depending on restrictions. The data structure is the same for
both access locations.

   -​   Level 2 (qc-norm): Quality-controlled, normalized feature-by-sample matrices (columns are
        vialLabel; feature identifiers are assay-dependent) with associated feature and sample metadata,
        suitable for custom exploratory analyses and modeling.
   -​   Level 3 (da): Differential abundance tables with standardized contrasts (within-group changes and
        between-group delta-delta comparisons) including effect sizes, confidence intervals, and
        multiple-testing adjusted p-values.
   -​   Level 4 (when present): Downstream interpretation and integration outputs, including enrichment
        results (e.g., CAMERA-based and clustering-based enrichment summaries) and reference resources
        (e.g., HUMAN_FEATURE_TO_GENE, metabolomics CV filtering resources). These results are NOT
        available for download from the Data Hub, and must be accessed via the R package.

Analysis essentials, see publication for details
Core Model: A linear mixed effects model was fit for each molecular feature using the dream function from the
variancePartition R package. For count-based data (transcriptomics, ATAC-seq), voomWithDreamWeights was
applied first.

Primary Comparison: The main results were generated using a "difference-in-changes" model. This compares
the change from a pre-exercise baseline to a later timepoint within an exercise group (resistance or endurance)
against the corresponding change in the non-exercising control group. These contrasts are specified in the DA
tables.

Model Covariates: The final models included the following terms:

   ●​ Fixed Effects: group (RE, EE, CON), timepoint (as a cell-means interaction with group), clinical site,
      age, sex, and BMI.
   ●​ Random Effect: participant id was included to account for repeated measures from the same individual.
   ●​ Note: Race, ethnicity, and genetic ancestry were evaluated but not included as they did not improve
      model fit (based on BIC).

Model Selection:

The dream model was selected after a large-scale simulation study showed it provided the best balance of
high statistical power while maintaining the target Type 1 error rate (FDR ≈ 5%) compared to six other common
methods.

Additional Comparisons: Two other types of comparisons were made:

   ●​ Group-Specific: Change from baseline within a single exercise group (e.g., RE post-exercise vs. RE
      pre-exercise).
   ●​ RE vs. EE: A direct comparison of the change from baseline in the resistance group versus the
      endurance group.
Data Filtering: For a feature to be included in an analysis, a minimum of 3 participants with paired pre- and
post-exercise samples were required in each group being compared. Features not meeting this criterion were
excluded from differential analysis.

Significance Threshold: P-values for all comparisons were adjusted using the Benjamini-Hochberg method. A
feature was considered statistically significant at a False Discovery Rate (FDR) of 0.05.


For users new to MoTrPAC analysis results
   -​   Start with Level 2 qc-norm when you want a cleaned, analysis-ready matrix for exploratory analysis,
        visualization, and custom modeling.
   -​   Use Level 3 da tables when you want standardized differential analysis results (effect sizes,
        p-values/FDR) for predefined contrasts/tests.
   -​   Use the packaged phenotype/clinical metadata (e.g., pheno in R package) to subset and annotate
        samples (e.g., group assignment, sex, time point).


For users familiar with other MoTrPAC analysis releases
   -​   The release is tied to QC data freeze v1.3; see Section 4 for full version history, known issues, and
        compatibility notes.
   -​   This collection is a DSMB-constrained subset: only the adult sedentary cohort is permitted for
        downstream analysis; other concurrently generated groups may exist internally for QC but are not part
        of the official analysis release.


2.1 Experimental factors
   -​   Cohort: adult sedentary participants (pre-suspension / pre-COVID phase).
   -​   Randomized group: ADUEndur (EE, endurance), ADUResist (RE, resistance), ADUControl (CON,
        control).
   -​   Timepoints (acute bout; see Section 1): pre_exercise, during-exercise draws, and multiple
        post-exercise timepoints up to post_24_hr (assay/tissue dependent). See timepoints above.
   -​   Tissues: analysis uses three overarching categories (blood, muscle, adipose) mapped from
        MoTrPAC tissue codes (see OME_TISSUE_CODE and Section 1).


2.2 Identifiers and joins
   -​   pid is the participant-level identifier and is used for participant-level joins across clinical/phenotype
        datasets and summaries.
   -​   vialLabel is the biospecimen/sample identifier used as:
           -​ column names in Level 2 qc-norm matrices (*_QC$qc_norm),
           -​ the join key between sample-level metadata and the clinical/phenotype table pheno$data.
   -​   feature_id is the feature identifier used for feature-level joins:
           -​ qc-norm matrices use an assay-dependent feature identifier as rownames (see Section 5.2.1),
           -​ DA tables include a feature_id column,
           -​ the reference mapping HUMAN_FEATURE_TO_GENE is keyed by feature_id (and assay).

Note on casing: the consortium release notes prefer snake_case (e.g., vial_label), but existing packaged
objects may also use camelCase variants (e.g., vialLabel) depending on file provenance.
2.3 Sample sizes
As summarized in Section 1 (Scope & scale):

   -​   175 unique participants (pid) are represented.
   -​   13,778 unique samples (vialLabel)
   -​   Participant group counts (unique pid, adult sedentary cohort, baseline visit): ADUResist = 73,
        ADUEndur = 65, ADUControl = 37.
   -​   Sex distribution for these 175 participants (from pheno$data$sex_psca): Female = 126, Male = 49.
   -​   Ages for these 175 participants (from pheno$data$calculatedAge): min 18, median 41, max 73.

4.1 Known issues, limitations, and caveats (v1.2)
The consortium release readme describes the following issues that are relevant for analysis use (Levels 2–4):

   -​   Identifier/name casing inconsistencies: key identifiers may appear with mixed casing/styles across

        DA modeling.

5.2.3 Data Object Structure and Definitions

5.2.3.1 QC Norm objects
Common qc-norm object structure for *_QC objects:

   -​    *_QC$qc_norm: a data.frame with features as rownames and vialLabel values as column names
         (row identifiers are assay-dependent).
   -​    *_QC$sample_metadata: a data.frame keyed by vialLabel (may also include legacy variants
         such as vial_label and label_id depending on provenance).
   -​    *_QC$feature_metadata: a data.frame with assay-dependent feature descriptors (e.g., transcript
         feature_id, proteomics target IDs, metabolite descriptors such as metabolite_name/mz/rt).

Data Processing and Analysis Framework
The BIC ingests and disseminates a wide range of data for users. Below is an outline of the general approach
taken to molecular data. Similar structure exists for clinical/phenotypic data, though there are fewer levels of
processing (See Clinical/Phenotypic data collections)



Levels 0-1: Raw and Processed Data
Raw data (Level 0) consists of unprocessed instrumental output that cannot be directly analyzed. Processing
converts this raw data into quantifiable measurements (Level 1). Depending on the assay, this processing may
occur at the data generation site or at the BIC

Level 1 datasets represent the first layer of biologically interpretable information. These are direct
outputs from standardized bioinformatics pipelines specific to each omics platform:

   ●​ Transcriptomics: BAM files containing aligned sequencing reads are converted to gene expression
      matrices, where values represent read counts for each gene in each sample
   ●​ Proteomics: Raw mass spectrometry files are processed to identify peptides and proteins from
      spectral signatures and quantify their abundance
   ●​ Metabolomics: Instrumental data are processed to identify and quantify metabolite levels


📃  Typical data object formats:
   ●​ A structured feature-by-sample matrix where rows represent biological entities (genes, proteins,
      metabolites) and columns represent individual samples. These datasets serve as quality-controlled
      inputs for downstream analysis.
   ●​ Metadata tables for features and samples. These vary by assay


Level 2: Quality-Controlled Normalized Data
Level 2 data are normalized, batch-corrected, and filtered to remove outliers. This level is analysis-specific
because the additional steps require consideration of the experimental design and scientific question.

Platform-specific normalization methods are applied:

   ●​   Transcriptomics: TMM normalization to account for sequencing depth differences
   ●​   Proteomics and Metabolomics: Median absolute deviation (MAD) scaling
   ●​   Metabolomics: Missing value imputation is commonly applied
   ●​   Proteomics: Missing values are typically not imputed


📃  Typical data object formats:
   ●​ A structured feature-by-sample matrix where rows represent biological entities (genes, proteins,
      metabolites) and columns represent individual samples. These datasets serve as analysis specific,
      individual level data inputs for downstream analysis.
   ●​ Metadata tables for features and samples. These vary by assay.
Level 3: Differential Abundance Analysis
Differential analysis identifies variations in molecular abundance between experimental groups. This provides
analyte-specific estimates of experimental effects. Statistical methods are selected based on experimental
design and may include:

   ●​   Contrasts to control measurements
   ●​   Mixed models for repeated measures
   ●​   Multiple comparison correction
   ●​   Covariate adjustment


📃  Typical data object formats:
   ●​ A differential abundance (DA) table typically has one feature analyzed using one model per row.
      Columns in this table fall into three general categories
          ○​ Feature metadata (e.g. omic layer, tissue source)
          ○​ Model metadata (e.g. mixed effects model, covariats, contrast of interest)
          ○​ Summary statistics (e.g. beta coefficient, confidence intervals, p-value, adjusted p-value)


Level 4: Multi-Omics Integration and Biological Interpretation
Multi-omics integration methods vary based on research objectives and typically employ data science
approaches including feature reduction, clustering, and network analysis.

Multi-omics analysis leverages existing biological knowledge for enhanced interpretation:

   ●​ Pathway enrichment analysis identifies biological processes modulated by the intervention using
      Gene Set Enrichment Analysis (GSEA), over-representation analysis, and databases including Gene
      Ontology, KEGG, and Reactome
   ●​ Transcription factor analysis uses genomic motif analysis tools (e.g., HOMER) to identify regulatory
      factors controlling observed expression changes
   ●​ Gene regulatory network modeling applies specialized tools to model regulatory relationships from
      multi-omics data

Cross-species comparative analysis enables translation between animal models and human studies by:

   ●​ Mapping orthologous genes and proteins between species
   ●​ Identifying conserved molecular signatures and pathways
   ●​ Generating translational hypotheses for human health applications


📃  Typical data object formats:
   ●​ Pathway enrichment results:
         ○​ Pathway metadata, enrichment statistics
   ●​ Transcription factor analysis
         ○​ Transcription factor gene symbol, enrichment statistics
   ●​ Gene regulatory network
         ○​ Edge and node identifications and metrics
